# Atelier Estética — Nexora v3

Projeto demonstrativo reconstruído sobre a **Nexora Website Platform v3**.

## O que foi explorado da base

- Design DNA (`archetype`, geometry, layout, imagery, elevation, motion e backgrounds);
- `PageComposer` com composição declarativa;
- client extension layer em `src/client/` para blocos realmente exclusivos;
- componentes `Section`, `Container`, `SmartImage`, `Reveal`, `Button` e `ContactForm`;
- páginas de serviços, galeria, FAQ, contato e legais;
- Form Engine, validação, rate limit e proteção contra spam;
- SEO/JSON-LD, sitemap, robots, OG dinâmica e health endpoint;
- Studio local em `/dev/studio` durante desenvolvimento;
- auditorias de imagem, arquitetura, composição, presets e media;
- responsividade e acessibilidade da base.

## Preview rápido

Abra `ABRIR-PREVIEW.bat` para visualizar uma representação estática da direção visual sem instalar dependências.

## Projeto real Nexora/Next.js

Execute `INICIAR-SITE.bat`. Na primeira execução, a base instala as dependências e abre `http://localhost:3000`.

O projeto usa apenas conteúdo demonstrativo. O placeholder técnico de WhatsApp exigido pelo contrato atual da plataforma não é exibido no site; contatos reais devem ser configurados antes de publicação.
